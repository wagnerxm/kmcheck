# KM Check — Plano de Capturas para o Manual

## Convenções
- **Orientação**: V = vertical (retrato), H = horizontal (paisagem)
- **Auto**: pode ser capturada no navegador desktop (sem GPS/câmera real)
- **Manual**: requer dispositivo real (celular) com GPS e/ou câmera
