# KM Check — Resumo das Telas

| # | Tela | Funcao Principal | Acesso |
|---|------|-----------------|--------|
| 1 | Tela Inicial | Painel com KM, coordenadas, acesso rapido | Tela de abertura |
| 2 | Camera | Captura de foto com legenda automatica | Botao "Registrar Evidencia" |
| 3 | Configuracoes > Camera | Resolucao, qualidade, formato, tema | Cartao "Configuracoes" |
| 4 | Configuracoes > Logo | Logo personalizada sobre a foto | Aba "Logo" |
| 5 | Configuracoes > Legenda | Posicao, tamanho, cor, conteudo | Aba "Legenda" |
| 6 | Gestao de Eixo | Baixar rodovias do SNV/DNIT | Cartao "Gestao de Eixo" |
| 7 | Importar Arquivo | Shapefile, ZIP, KMZ, CSV | Secao na Gestao de Eixo |
| 8 | Consulta | Coordenada para KM e vice-versa | Icone de lupa |
| 9 | Galeria | Visualizar fotos capturadas | Icone na camera |

## Fluxo Principal

```
Tela Inicial → Camera → Foto com Legenda → Galeria
```

## Fluxo de Configuracao

```
Tela Inicial → Configuracoes → Camera / Logo / Legenda
```

## Fluxo de Importacao

```
Tela Inicial → Gestao de Eixo → Baixar SNV ou Importar Arquivo
```

## Requisitos

- **GPS:** Necessario para KM automatico e coordenadas
- **Internet:** Apenas para primeiro acesso e download de rodovias
- **Camera:** Necessaria para captura de fotos
- **Sensor de Movimento:** Deteccao de orientacao (paisagem/retrato)
